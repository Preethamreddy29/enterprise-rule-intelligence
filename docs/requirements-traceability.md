## Traceability maintenance

On every feature/ADR/API/data-flow change, map acceptance criteria to code, tests, and reproducible evidence. Keep identifiers stable and split rows when one test cannot prove all claims. Release statuses must be changed only with exact evidence links; Phase 0 plans do not satisfy v1 gates.
